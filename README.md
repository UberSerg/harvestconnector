# harvestconnector

Протокол подключения **внешнего Harvester** к [Live Harvest](https://github.com/UberSerg) (MVP v0.1).

## Главный документ

→ **[PROTOCOL.md](./PROTOCOL.md)** — технический паспорт: Core, STANDARD, Harvester, privacy, формат пакета поглощения `lh_ingest_version: 1`.

## Назначение

Использовать ChatGPT (в т.ч. голосовой режим) как внешнего сборщика знаний: интервью → пакет YAML → поглощение в локальный `harvest/` через Cursor / контроллер с доступом к файлам.

## Быстрый старт

1. Открыть [PROTOCOL.md](./PROTOCOL.md).
2. Вставить паспорт (или ссылку + ключевые разделы) в ChatGPT.
3. Сказать: «Работай харвестором».
4. В конце сессии забрать пакет `lh_ingest_version: 1`.
5. Передать пакет в Cursor: «поглоти пакет Live Harvest».

## Важно

- В этом репозитории **нет** персональных знаний.
- SoT о человеке остаётся в локальном `harvest/`.
- Секреты доступа в пакет и в базу не пишутся.
